##             Qunix Theme for Calagopus

A premium, highly customizable theme extension for the Calagopus Panel. Control every visual aspect of your hosting environment through an intuitive admin interface.

### ✨ Key Features

* **Dynamic Backgrounds:** Support for custom wallpaper URLs with adjustable **Blur** and **Brightness** filters.
* **Glassmorphism UI:** Integrated **Glass Transparency** and **Shadow Opacity** controls for a modern, frosted-glass aesthetic.
* **Global Color Management:** Easily customize Background, Text, Focus, and Border colors across the entire panel.
* **Precision Layout:** Fine-tune **Navbar Height**, **Sidebar Gap**, and **Corner Radius** (Cards, Inputs, Buttons) in pixels.
* **Modular Overrides:** Dedicated settings for Terminal, Code Editor, and List/Table views.
* **Clean Integration:** Pure extension (.c7s) with no core file modifications.

### 🎨 Theming Scope

* **Global:** Wallpapers, glass transparency, and primary brand accents.
* **Navigation:** Navbar height, sidebar spacing, and mobile-specific coloring.
* **Elements:** Cards, inputs, buttons, and custom border radii.
* **Tools:** Adaptive styling for the Terminal and File Manager Code Editor.

### 🚀 Installation

1. Download the `qunix_theme.c7s.zip` file.
2. Navigate to **Admin Panel > Extensions**.
3. Upload the `.c7s.zip` file.
4. Click **Rebuild Extensions** and wait for completion.
5. Access customization via **Admin > Qunix Theme Settings**.

### 📋 Requirements

* **Calagopus Panel:** v1.0.0 or higher.
